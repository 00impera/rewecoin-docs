ReweCoin (RWC) — Whitepaper

Version 0.2 — Draft, October 2026

Parameters are verified from the ReweCoin mainnet node and its consensus source. Sections marked TBD are open for the team to finalize; no invented figures.

1. What is ReweCoin?

ReweCoin (RWC) is an independent Proof-of-Work blockchain built on the Zcash codebase (zcashd 6.0.0). Mainnet launched on September 21, 2026 with no protocol-level premine, no founders' reward in the consensus rules and no genesis allocation. All blocks mined to date (height 2388, October 4, 2026) were mined by the project team; public mining is not yet open.

It inherits Zcash's transaction model (transparent and shielded pools, UTXO ledger) and Equihash consensus, as a fully separate chain with its own genesis, emission schedule and parameters.

3. How does it work?

3.1 Consensus

Proof-of-Work with Equihash 200,9, memory-hard and designed to keep mining accessible.

  • Target block time: 75 s
  • Difficulty adjustment: dynamic, per block (inherited from zcashd)

3.2 Transaction model

Transparent and shielded pools (Sapling/Orchard present in the protocol; usage so far is mostly transparent). Mainnet addresses start with C7.

3.4 Mining pool (in testing)

  • Stratum server for Equihash 200,9, including NU5 block templates.
  • Local Equihash verification of every solution before it reaches the node.
  • Payout address required: miners connect as -u ADDRESS.worker; the address is validated by the node.
  • Found blocks are journaled; payouts wait for coinbase maturity (101 blocks), skip orphans, and are idempotent.
  • Not yet implemented: variable difficulty (vardiff), PPLNS share accounting, TLS.

5. Supply and emission

Detail: tokenomics/supply-and-emission

  • Initial block reward: 50 RWC
  • Halving interval: 840,960 blocks (~2 years)
  • Premine: none at protocol level (no genesis allocation, no founders' reward). All blocks mined to date by the project team; public mining not yet open
  • Asymptotic supply: ~84,093,434 RWC
  • Technical overflow cap: 100,000,000 RWC (not the target)
